# care-chatbot

심리 상담 챗봇의 효과를 실험 데이터로 검증한 연구 프로젝트. 생성형·검색형 LLM 챗봇의 사용자 만족도와 심리 개선 효과를 비교 분석하고, LLM 기반 자동 평가의 한계를 함께 검토했다.

---

## 배경

코로나 팬데믹 이후 우울·불안 인구가 급증했으나, 정신과 치료에 대한 사회적 편견과 높은 비용으로 실제 치료 접근률은 낮다. 이에 LLM 기반 심리 상담 챗봇으로 진입장벽을 낮추려는 시도가 증가하고 있다.

본 프로젝트에서는 두 단계로 연구를 진행했다.

1. GPT-3.5·GPT-4.0 챗봇의 실제 사용자 만족도를 측정하고, gpt-4-turbo를 이용한 LLM 자동 평가와 비교
2. 검색형(Retrieval) 챗봇과 생성형(HyperCLOVA·GPT-3.5·GPT-4.0) 챗봇 4종을 만족도 평가 및 심리검사 기준으로 비교

---

## 연구 1 — 사용자 만족도 vs LLM 기반 평가 비교 (KCC2024)

### 데이터

- 총 80명 (챗봇v3.5: 37명, 챗봇v4.0: 43명)
- 1일 1회 취침 전 상담, 5회 이상 답변 경험 후 3개를 무작위 선택해 평가
- 총 평가 횟수: 챗봇v3.5 239회 / 챗봇v4.0 254회
- LLM 자동 평가 대상: 챗봇v3.5 1,368개 · 챗봇v4.0 1,352개 (총 2,720개 응답)

### 평가 항목 (5점 리커트)

해결방법 적절성 / 설득적인 표현 / 답변의 부드러운 정도 / 심리적 위안 / 고민·답변 연관성 / 문장 완성도 / 종합만족도 / 사용자 노력 점수

### 결과

|  | 챗봇v3.5 | 챗봇v4.0 |
|---|---|---|
| 이용 일수 (평균) | **7.24일** | 7.05일 |
| 사용자 만족도 | 3.81점 | **3.90점** |
| LLM 자동 평가 (gpt-4-turbo) | 4.28점 | **4.32점** |

- 사용자 만족도는 GPT-4.0이 근소하게 높았으나, GPT-3.5 사용자는 이용 일수가 더 길었음 — 빠른 응답 속도가 사용 빈도를 높인 것으로 분석
- gpt-4-turbo는 챗봇 유형과 무관하게 대부분의 답변을 3.5점 이상으로 평가해 실제 사용자 체감과 동떨어진 결과를 보임 — LLM이 감정적 측면을 충분히 반영하지 못하기 때문으로 해석

## 연구 2 — 검색형·생성형 챗봇 유용성 비교 (KSC2024)

### 챗봇 구성

| 챗봇 | 유형 | 기반 모델 |
|---|---|---|
| 챗봇R | 검색형 | 이별 커뮤니티 공감 응답 데이터셋 |
| 챗봇H | 생성형 | HyperCLOVA |
| 챗봇G3.5 | 생성형 | GPT-3.5 |
| 챗봇G4.0 | 생성형 | GPT-4.0 |

프롬프트: "당신은 심리상담가이며 내담자의 말에 따뜻한 말투로 응답해 주세요."

### 데이터

- 213명 (PHQ-9 10점 이상 중등도 우울 선별)
- 1일 1회 상담 후 평가지 작성, 총 1,466건 수집
- 참여 전·후 심리검사 4종 실시: ISI (불면증) · GAD-7 (불안) · TEQ (공감) · PHQ-9 (우울)

### 평가 방법

- **Turn Level Evaluation (7항목)**: 해결방법 적절성 / 설득하는 표현 / 부드러운 태도 / 심리적 위안 / 질문 연관성 / 고민 연관성 / 문장 완결성
- **Session Level Evaluation (3항목)**: 종합만족도 / 사용자 노력 점수 / 추천 정도
- **심리검사**: 사전·사후 점수 변화로 실질적 심리 개선 여부 측정

### 결과

| 평가 | 챗봇R | 챗봇H | 챗봇G3.5 | 챗봇G4.0 |
|---|---|---|---|---|
| Turn Level (7항목 합) | 24.91 | 25.34 | **29.46** | 29.24 |
| Session Level (3항목 합) | 9.79 | 10.05 | 11.33 | **11.45** |
| 심리검사 개선 합계 | -5.45 | -5.74 | -2.60 | **-6.74** |

**Turn Level 세부: 부드러운 태도** — 챗봇R **4.13** > G3.5 4.10 > G4.0 3.93 > H 3.39

**심리검사 변화율 (전체 평균)**

| 지표 | 변화율 |
|---|---|
| ISI (불면증) | -6.69% |
| GAD-7 (불안) | -16.52% |
| PHQ-9 (우울) | -16.05% |

GPT-4.0 사용자의 PHQ-9 개선: **-3.62점** (GPT-3.5: -0.96점 대비 약 3.8배)

### 결론

- 14개 평가 항목 중 GPT-4.0이 8개에서 최고점 → **GPT-4.0을 base model로 채택 권장**
- 단, 부드러운 태도는 공감 응답 기반의 챗봇R이 우세 → 검색형·생성형 결합 하이브리드 구조 제안
